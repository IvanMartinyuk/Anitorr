# Anime Tracker

A Flutter application for tracking anime, discovering what to watch next, and eventually acting as a companion for a personal anime media server.

## Goals

- Track watched anime
- Track progress
- PC version downloads new series automatically
- Receive notifications for new episodes
- Anime roulette
- Beautiful UI
- Cross-platform

## Planned platforms

- Android 
- iOS
- Linux/Windows (first)
- macOS

## Tech Stack

- Flutter
- Riverpod
- GoRouter

## Running

```bash
flutter pub get
flutter run -d linux
flutter run -d windows
```
